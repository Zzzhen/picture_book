## 模板化痕迹检查

- 无渐变主视觉、玻璃拟态、通用 SaaS 数据大屏或无意义大标题。
- 宋体只用于馆名、书名和章节标题；正文使用系统无衬线字体。
- 森林绿承担主操作，陶土红仅用于藏书票、审核来源和必要风险提示。
- 家藏书票只出现在启动、首次建馆和绘本馆首页，不在每个空状态重复使用。
- 管理员指标页明确写出“只展示指标，不设置成功阈值”，不使用红绿达标色。
- 手工录入将作者降为可选项；待审核修改和驳回重提使用不同动作文案，避免状态误导。
- 书架普通状态使用`编辑｜选择`两个低强调文字动作；选择状态将`选择书籍`和实时计数置于视觉中心，危险的`移出书架`与中性的`置顶`在固定底栏中明确分离。
- 编辑书架只保留名称和说明；添加绘本使用独立页面，避免一个页面同时承担资料编辑和关系管理。
- 连续扫码取消四宫格汇总卡和独立汇总页；相同 ISBN 在同页合并，朱砂色只用于删除与失败，森林绿只承担开始扫码、确认入馆和成功状态。
- 连续扫码只有一处视觉冒险：顶部“扫描票据”用虚线票根编码 100 次上限；其余列表和操作保持安静，避免模板化装饰。
